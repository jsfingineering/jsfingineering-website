- Click-to-email, phone and WhatsApp links
- No build system required

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders from this directory, preserving the `assets/` and `pages/` folders.
3. In GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.
4. Open the generated GitHub Pages URL.
5. For the custom domain, configure GitHub Pages with `www.jsfingineering.com` and set the DNS records at the domain provider as instructed by GitHub.
