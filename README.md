## Hosting
This is a pure HTML/CSS/JavaScript static site. It can be hosted on Cloudflare Pages, GitHub Pages, Netlify, Vercel, or conventional web hosting.

No PHP, Node.js, database or server is required for the current version.

## Contact form
The contact form uses `mailto:official@jsfingineering.com`, so it opens the visitor's email client. If a server-side enquiry form is required later, connect it to a form service or backend without changing the front-end structure.

## Domain
Canonical site: https://www.jsfingineering.com

## Update workflow
Keep GitHub as the master source. Update files, commit/push, and let the hosting platform deploy automatically.
